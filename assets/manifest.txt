# PureC OS install asset manifest — single source of truth for every file
# the installer seeds into the target filesystem.
#
# Columns (whitespace separated, exactly 5):
#   module    Limine boot module path (also the ISO path). Must start with /.
#   dest      Target filesystem path. Parent directories are auto-created.
#   alias     8.3 alias path for non-8.3 names, or - for a direct write.
#   required  1 = missing/broken module aborts install, 0 = warn and skip.
#   stage     Host path (relative to repo ROOT) used to stage the ISO module.
#
# Consumers (all generated/validated by mk/gen_assets.py, installed by the
# generic manifest loop in src/fs/fat/fat32.c):
#   - ISO staging: ROOT/<stage> -> <ISO_ROOT><module>
#   - limine.conf: one "module_path: boot():<module>" per unique module
#     (+ /manifest.txt itself), optional modules only if the stage exists.
#   - installer: for each line, boot_get_module(<module>) -> write <dest>
#     (via alias when set) -> verify. No per-file C code needed.
#
# Rules: no spaces inside fields; lines starting with # are comments;
# (module,dest) pairs must be unique; a module may feed several dests.
# The installer fetches /manifest.txt directly, so it needs no entry here.
