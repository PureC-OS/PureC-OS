# Драйвер мыши PS/2 и общий слой указателя

Драйвер читает пакеты мыши PS/2 с вспомогательного порта i8042 и ведёт общее состояние указателя (`struct mouse_state`). Этим состоянием пользуются все источники движения: мышь PS/2, [USB-мышь](usb-mouse.md) и [тачпад I2C-HID](i2c-hid-touchpad.md). Драйвер также рисует курсор поверх framebuffer и даёт отладочный оверлей.

Главный вход для всех источников — `mouse_handle_relative(buttons, dx, dy)`. Он применяет ускорение, ограничивает координаты размером экрана и помечает курсор для перерисовки.

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/mouse/ps2_mouse.h` | Структуры состояния и публичный API |
| `src/drivers/mouse/ps2_mouse.c` | Инициализация контроллера, разбор пакетов, курсор, отладочный оверлей |

## Публичный API

### Инициализация и опрос

| Функция | Что делает |
|---------|------------|
| `ps2_mouse_init()` | Включает вспомогательный порт, сбрасывает мышь, пробует IntelliMouse (4-байтный пакет), включает передачу, разрешает IRQ12 |
| `ps2_mouse_handler()` | Обработчик IRQ12 (вектор 44): читает один байт из порта `0x60` |
| `ps2_mouse_poll()` | Опрос без прерывания: читает один байт, если он есть от мыши |

### Состояние

| Функция | Что делает |
|---------|------------|
| `mouse_get_state()` | Копия `struct mouse_state` под `cli` (`x`, `y`, `dx`, `dy`, `buttons`, `has_data`, `wheel`) |
| `mouse_get_debug_state()` | Счётчики прерываний, опроса, пакетов, последний байт, ACK-ответы |
| `mouse_set_bounds(w, h)` | Размер экрана для ограничения координат |
| `mouse_add_wheel(delta)` | Накапливает прокрутку колёсиком |
| `mouse_handle_relative(buttons, dx, dy)` | Общий вход движения и кнопок |

### Отрисовка

| Функция | Что делает |
|---------|------------|
| `mouse_redraw()` | Полная перерисовка курсора и оверлея |
| `mouse_begin_framebuffer_update()` / `mouse_end_framebuffer_update()` | Пакетная перерисовка: без backbuffer стирает курсор перед обновлением, в конце рисует его заново |
| `mouse_end_framebuffer_update_keep()` | То же, но без перерисовки курсора |
| `mouse_flush_pending()` | Выполняет отложенную перерисовку, если движение пришло из прерывания |
| `mouse_set_debug_overlay(bool)`, `mouse_get_debug_overlay()` | Включение отладочной панели с координатами и счётчиками |

## Инициализация (`ps2_mouse_init`)

1. Если статус i8042 равен `0xFF`, контроллера нет, инициализация завершается.
2. Включается вспомогательный порт (`0xA8`), читается конфигурация (`0x20`), в ней выставляется бит IRQ12 (`0x02`) и сбрасывается бит отключения вспомогательного порта (`0x20`).
3. Мышь получает `0xFF` (сброс), `0xF6` (значения по умолчанию).
4. Попытка IntelliMouse: последовательность sample rate 200, 100, 80 и запрос ID `0xF2`. Если ответ `3`, размер пакета становится 4 байта (колёсико).
5. Частота опроса выставляется на 100 (`0xF3`), включается передача (`0xF4`).
6. При успехе в PIC размаскируются IRQ2 (каскад) и IRQ12.
7. Курсор ставится в центр экрана. Размер берётся из GOP, если он доступен. Иначе используется текстовый экран 80×25 с ячейкой 8×16 (границы 640×400).

Если какой-то шаг не проходит, драйвер переходит на метку `ps2_init_no_mouse`, помечает мышь отсутствующей и не падает.

## Разбор пакетов (`process_mouse_byte`)

- Первый байт пакета должен иметь бит `0x08` (всегда единица). Если бит не стоит, байт отбрасывается, пакет пересинхронизируется.
- Пакет из 3 байт (или 4 с колёсиком): байт 0 — кнопки (`0x07`) и флаги переполнения (`0x40` по X, `0x80` по Y), байты 1–2 — смещения в дополнительном коде. Ось Y инвертируется, потому что у PS/2 она направлена вверх.
- Колёсико — младшие 4 бита четвёртого байта, со знаком.
- Переполненное смещение обнуляется (флаги `0x40`/`0x80`).

## Ускорение

`accelerate_axis` масштабирует смещение: коэффициент 1 при величине до 3, затем растёт на 48/256 за единицу и ограничивается 3× (768/256). Остаток сохраняется между пакетами (`accel_x`, `accel_y`), поэтому мелкие движения не теряются.

## Курсор и отрисовка

- Курсор 32×32 пикселя, белый с чёрной рамкой (`cursor_pixel`). Фон под курсором сохраняется в `bg_buf` (`save_bg`) и восстанавливается перед перемещением (`restore_bg`).
- Если GOP с backbuffer доступен, курсор передаётся композитору через `compositor_cursor_move`. Без backbuffer курсор рисуется прямо в framebuffer через `gop_put_pixel`, а фон сохраняется в `bg_buf`.
- Перерисовка откладывается, если прерывание пришло во время обновления экрана: флаг `mouse_ui_pending` сбрасывается в `mouse_flush_pending`.
- Отладочный оверлей (`draw_debug_overlay`) показывает координаты, кнопки, счётчики прерываний и пакетов в шестнадцатеричном виде.

## Где используется

- `src/boot/boot.c` и `src/boot/grub_main.c` — `ps2_mouse_init()` при загрузке.
- `src/kernel/syscall/syscall.c` — системный вызов `GET_MOUSE` (через `mouse_get_state` и `ps2_mouse_poll`).
- `src/userspace/userspace.c` — опрос мыши и USB-мыши в цикле, передача размеров экрана через `mouse_set_bounds`.
- `src/userspace/display_mode.c` — `mouse_set_bounds` после смены режима.
- `src/drivers/usb/xhci.c` — через `usb_mouse_report` попадает в `mouse_handle_relative`.
- `src/drivers/input/i2c_hid_touchpad/` — движение тачпада через `mouse_handle_relative`.

## Ограничения

- Двумя способами читается один и тот же порт `0x60`: через обработчик IRQ12 и через `ps2_mouse_poll`. Одновременное чтение двумя путями может потерять или раздвоить байт. Сейчас оба вызываются из одного ядра, но гарантии нет.
- Нет поддержки 5-кнопочных мышей и протокола IntelliMouse Explorer (кнопки 4 и 5).
- Размер курсора фиксирован (32×32), цвет не настраивается.
- Ускорение жёстко задано, из пользовательского режима его нельзя изменить.
- При смене разрешения надо вызвать `mouse_set_bounds`, иначе координаты могут выйти за экран.
- Без GOP курсор — это одна ячейка текстового экрана VGA (`0xB8000`), координаты переводятся делением на 8×16. Курсор 32×32 при этом не рисуется.
