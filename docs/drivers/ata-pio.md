# Драйвер ATA PIO (legacy IDE)

Драйвер накопителей в режиме PIO по классическим портам IDE. Работает с четырьмя возможными устройствами: первичный и вторичный каналы (`0x1F0` и `0x170`), по два диска на канал (master и slave). Данные передаются через регистр данных, процессор копирует каждое слово сам. Это самый медленный, но самый простой путь к диску: он не требует PCI, DMA и прерываний.

Драйвер нужен в основном для старых машин, виртуальных машин с IDE-контроллером и отладки. На современном железе SATA-диски обычно идут через [AHCI](ahci.md).

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/storage/ata_pio.h` | Публичный API |
| `src/drivers/storage/ata_pio.c` | Реализация (около 320 строк) |

## Публичный API

| Функция | Что делает |
|---------|------------|
| `ata_pio_init()` | Опрашивает четыре возможных устройства через IDENTIFY, сохраняет найденные |
| `ata_pio_device_count()` | Число найденных дисков (до 4) |
| `ata_pio_get_device_info(i, info)` | Сведения о диске для блочного слоя |
| `ata_pio_select_device(i)` | Выбор текущего диска |
| `ata_pio_read_sector(lba, buf)`, `ata_pio_write_sector(lba, buf)` | Один сектор 512 байт |
| `ata_pio_flush()` | Команда `FLUSH CACHE` (`0xE7`) |
| `ata_pio_device_name()` | Имя текущего диска |

## Инициализация

Таблица кандидатов перебирается по порядку:

| Номер | I/O порт | Порт управления | Канал | Диск |
|-------|----------|-----------------|-------|------|
| 0 | `0x1F0` | `0x3F6` | первичный | master |
| 1 | `0x1F0` | `0x3F6` | первичный | slave |
| 2 | `0x170` | `0x376` | вторичный | master |
| 3 | `0x170` | `0x376` | вторичный | slave |

Для каждого кандидата `identify_device`:

1. Выключает прерывания контроллера (бит `nIEN` через порт управления, значение `2`) и выбирает диск (`0xA0` для master, `0xB0` для slave).
2. Посылает команду IDENTIFY (`0xEC`) и читает статус. Значения `0` и `0xFF` означают отсутствие контроллера, пропуск кандидата.
3. Проверяет регистры `LBA_MID` и `LBA_HIGH`: если там не нули, устройство не ATA (например, ATAPI), пропуск.
4. Читает 256 слов IDENTIFY. Проверяет бит LBA в слове 49. Если поддерживается LBA48 (слово 83, бит 10), размер берётся из слов 100–103. Иначе из слов 60–61.
5. Размер сектора 512 байт. Для LBA28 адресуемое пространство ограничено `0x10000000` секторами (128 ГБ).

Найденные диски получают имена `/dev/sdX` через `set_linux_name`, по номеру `device_count`.

## Чтение и запись

- **Чтение** (`ata_pio_read_sector`): команда `READ SECTORS` (`0x20`) с LBA28. Ожидание DRQ, затем 256 раз `inw` из регистра данных. После чтения ждётся 400 нс (`delay_400ns`, четыре чтения `control_base`).
- **Запись** (`ata_pio_write_sector`): команда `WRITE SECTORS` (`0x30`), ожидание DRQ, затем 256 раз `outw`, затем ожидание завершения.
- **Выбор адреса** (`select_lba`): регистр `DRIVE` получает старшие четыре бита LBA и флаг LBA-режима (`0xE0`). Затем записываются счётчик секторов (1) и три байта LBA.

Все ожидания ограничены `ATA_POLL_LIMIT` = 1 000 000 итераций опроса статуса.

## Где используется

- `src/drivers/storage/block_device.c` — блочный слой вызывает `ata_pio_init()` первым (приоритет ATA PIO выше остальных транспортов).
- `src/drivers/storage/block_device.c` — `ata_pio_get_device_info` и `ata_pio_select_device` при выборе диска.

## Ограничения

- Только LBA28 для чтения и записи. Адреса за пределами 128 ГБ отклоняются, даже если IDENTIFY сообщает больший размер диска. Драйвер не использует LBA48.
- Один сектор за команду. Блочный слой не объединяет запросы, поэтому пропускная способность низкая.
- Процессор копирует каждое слово сам. Во время чтения или записи ядро занято, и другие потоки на этом ядре задерживаются.
- Драйвер опрашивает статус, прерывания IRQ14 и IRQ15 не используются.
- ATAPI-устройства (оптические приводы) не распознаются: IDENTIFY у них возвращает другие сигнатуры, и кандидат пропускается.
- Нет обработки горячего подключения. Диски ищутся только при инициализации.
- Нет таймаута по времени: `ATA_POLL_LIMIT` ограничивает число обращений к порту, а на медленном или сбойном контроллере это может быть несколько секунд.
