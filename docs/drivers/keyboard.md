# Драйвер клавиатуры PS/2 (i8042)

Драйвер читает скан-коды из контроллера i8042 (порты `0x60` и `0x64`). Работает в режиме опроса: прерывание IRQ1 на PIC маскируется в `keyboard_init`, а данные забираются при вызове `keyboard_poll()`. Драйвер понимает скан-коды обоих наборов (set 1 и set 2), переводит их в символы и в коды HID и складывает результат в три кольцевых буфера: символы, специальные клавиши и события нажатия/отпускания.

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/input/keyboard.h` | Публичный API и перечисление `keyboard_special_key` |
| `src/drivers/input/keyboard.c` | Реализация: декодеры, буферы, инициализация контроллера |
| `src/drivers/input/key_event.h` | Структура `struct key_event` и битовые маски модификаторов |
| `src/drivers/input/hid_keymap.h`, `hid_keymap.c` | Таблицы перевода set 1 и set 2 в коды HID Usage |

## Публичный API

| Функция | Что делает |
|---------|------------|
| `keyboard_init()` | Настраивает контроллер и устройство, выбирает набор скан-кодов, проверяет декодер |
| `keyboard_poll()` | Вычитывает всё, что готово в i8042, и разбирает скан-коды |
| `keyboard_has_key()` | Есть ли символ в буфере (после опроса) |
| `keyboard_try_getc(&c)` | Берёт символ, не ждёт |
| `keyboard_getc()` | Блокирующее чтение символа: в цикле вызывает `scheduler_yield()` |
| `keyboard_try_get_special(&k)` | Берёт специальную клавишу (F1–F3, Home, End, PgUp, PgDn, стрелки, Delete) |
| `keyboard_try_get_event(&ev)` | Берёт событие `struct key_event` (нажатие, отпускание, повтор, модификаторы) |
| `keyboard_set_leds(...)` | Заглушка, ничего не делает |

## Где используется

- `src/kernel/syscall/syscall.c:893–906` — системные вызовы чтения символа, спец-клавиши и события (`keyboard_getc`, `keyboard_try_getc`, `keyboard_try_get_special`, `keyboard_try_get_event`).
- `src/userspace/userspace.c:536` — `keyboard_init()` при инициализации пользовательского режима.
- `src/userspace/userspace.c:502, 576, 596–606, 682, 698` — опрос из цикла интерфейса и поток, который передаёт символы активному окну.

## Инициализация (`keyboard_init`)

1. Прерывания запрещаются на время настройки (`pushfq`/`cli`), в конце восстанавливаются.
2. `read_controller_config` отключает порты клавиатуры и мыши, сбрасывает буфер вывода, читает байт конфигурации и снова включает порты.
3. Если в конфигурации установлен бит трансляции (`0x40`), контроллер сам переводит set 2 в set 1, и драйвер работает с set 1. Иначе драйвер сам переключает клавиатуру на set 2 (`configure_native_scan_set2`).
4. Линия IRQ1 маскируется на PIC (`inb(0x21) | 0x02`), потому что драйвер работает опросом.
5. `decoder_self_test` подаёт встроенную последовательность (`A`, Enter, PgUp) и проверяет, что символы и спец-клавиши распознаны верно. Состояние после теста сбрасывается.

## Декодирование

- **Set 1.** Префикс `0xE0` — расширенная клавиша. Старший бит скан-кода означает отпускание. Таблицы `scancode_set1_map` и `scancode_set1_shift_map` дают символы, Shift и Caps Lock учитываются для букв. `Ctrl` + буква даёт управляющий код (`c - 'a' + 1`).
- **Set 2.** Байт `0xF0` перед кодом означает отпускание, `0xE0` — расширенная клавиша. Последовательность `0xE1` (Pause) пропускает семь байтов.
- Модификаторы: Shift (`0x2A`/`0x36` в set 1, `0x12`/`0x59` в set 2), Ctrl (`0x1D`/`0x14`), Caps Lock (`0x3A`/`0x58`).
- Функциональные клавиши F1–F3 и навигация попадают в буфер специальных клавиш, а не в буфер символов.

## Буферы

| Буфер | Размер | Переполнение |
|-------|--------|--------------|
| Символы `kbd_buf` | 128 байт | новые символы отбрасываются |
| Специальные клавиши | 16 | новые отбрасываются |
| События `event_buf` | 64 | самое старое выбрасывается |

Событие строится через `event_push`: отпускание клавиши, которая не была нажата, не попадает в буфер. Флаг `repeat` выставляется, если клавиша уже была нажата. Битовая карта нажатых клавиш `hid_down` хранится на 256 кодов HID.

## Ограничения

- Работа опросом, без прерываний. Клавиши обрабатываются только когда кто-то вызвал `keyboard_poll()`. Если пользовательский цикл долго не работает, ввод задерживается.
- Разбор скан-кодов и изменение буферов идут под `keyboard_lock` внутри `keyboard_poll`. `keyboard_init` и `decoder_self_test` блокировку не берут, поэтому их нельзя вызывать параллельно с опросом.
- Опрос вызывается из нескольких мест (системные вызовы и цикл пользовательского режима). Это первая точка для расследования известного бага на железе, когда одна клавиша печатает два символа. Причина пока не установлена.
- `keyboard_set_leds` не реализован: индикаторы Caps Lock и Num Lock на клавиатуре не загораются.
- Таблица символов для Set 2 ограничена латиницей и цифрами ASCII. Русская раскладка на уровне драйвера не поддерживается, её нужно добавлять на уровне приложения.
- Таблица HID по set 1 охватывает обычные клавиши и часть расширенных. Клавиши вне таблиц дают код 0 и не попадают в буферы.
- Ожидание контроллера ограничено 100 000 итерациями опроса. При неисправном i8042 `keyboard_init` завершится с ошибкой только после этого ожидания.
