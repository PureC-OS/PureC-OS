# Драйвер USB-мыши (HID boot protocol)

Тонкий слой между контроллером xHCI и общим указателем. Сам USB-протокол и опрос endpoint'а делает [xHCI](xhci.md): он находит HID-интерфейс с загрузочным протоколом мыши, переводит его в boot protocol и получает отчёты. Этот драйвер принимает отчёты, разбирает три обязательных байта (кнопки, X, Y) и четвёртый байт колёсика, и передаёт их в `mouse_handle_relative` и `mouse_add_wheel`.

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/mouse/usb_mouse.h` | Структура `usb_mouse_info` и API |
| `src/drivers/mouse/usb_mouse.c` | Реализация (около 45 строк) |

## Публичный API

| Функция | Что делает |
|---------|------------|
| `usb_mouse_attach(vid, pid, port)` | Помечает мышь подключённой, пишет в лог `boot mouse ready on xHCI portN` |
| `usb_mouse_detach()` | Помечает мышь отключённой, пишет предупреждение |
| `usb_mouse_report(buf, len)` | Разбирает отчёт и передаёт движение дальше. Нужно хотя бы три байта |
| `usb_mouse_poll()` | Вызывает `xhci_poll_mouse()`, если мышь подключена |
| `usb_mouse_get_info()` | Копия `struct usb_mouse_info` (счётчик отчётов, VID/PID, порт, признак подключения) |

## Формат отчёта boot protocol

| Байт | Содержимое |
|------|-----------|
| 0 | Кнопки: бит 0 — левая, бит 1 — правая, бит 2 — средняя (маска `0x07`) |
| 1 | Смещение X, знаковое |
| 2 | Смещение Y, знаковое. Направление: вниз — положительное, поэтому в драйвере оно передаётся как есть |
| 3 (необязательно) | Колёсико, знаковое |

В отличие от PS/2 инверсия по Y не нужна: в boot protocol ось Y уже направлена вниз, как и экранные координаты.

## Где используется

- `src/drivers/usb/xhci.c:1119` — `usb_mouse_attach` после того, как xHCI настроил boot-интерфейс мыши (`configure_boot_mouse`).
- `src/drivers/usb/xhci.c:346` и `:1607` — `usb_mouse_report` при получении отчёта.
- `src/drivers/usb/xhci.c:1519` — `usb_mouse_detach` при отключении порта.
- `src/userspace/userspace.c` и `src/kernel/syscall/syscall.c` — `usb_mouse_poll()` в цикле интерфейса и при системном вызове чтения мыши.

## Ограничения

- Работает только в загрузочном протоколе (boot protocol), который поддерживает мыши с тремя кнопками и колёсиком. Отчёты в report protocol с расширенными полями не разбираются.
- Один экземпляр мыши: `info` глобальный, второй подключённый манипулятор перезапишет первый.
- Мышь за USB-хабом не поддерживается. Драйвер EHCI прямо пишет, что мыши за хабом не работают (`src/drivers/usb/ehci.c:421`).
- Смещение одного отчёта ограничено знаковым байтом (`-128..127`). Драйвер не сглаживает и не объединяет отчёты.
