# Драйвер Wi-Fi Atheros AR9285 (порт ath9k)

Драйвер беспроводного адаптера Atheros AR9285 (PCI `168C:002B`, Wi-Fi 802.11 b/g/n, 2,4 ГГц). Код перенесён из Linux-драйвера ath9k: чип-специфичные части (`ath9k_hw.c`, `ath9k_eeprom.c`, регистры, таблицы инициализации) — порт с сохранением лицензии ISC и заголовков Atheros. Поверх него написана обвязка для PureC OS (`ar9285.c`), которая сканирует эфир, подключается к открытой сети и передаёт данные.

Работа ведётся на уровне один адаптер, 2,4 ГГц, HT20, только опрос без прерываний. По состоянию порта радио на железе ещё не проверено.

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/net/ath9k/include/ar9285.h` | Публичный API: `ar9285_init`, `ar9285_present` |
| `src/drivers/net/ath9k/ar9285.c` | Обвязка: PCI, сканирование, подключение, данные, MLME |
| `src/drivers/net/ath9k/ath9k_hw.c` | Ядро чипа: питание, сброс, PLL, калибровка, кольца RX и TX |
| `src/drivers/net/ath9k/ath9k_eeprom.c` | Чтение 4 КБ EEPROM, таблицы мощности передатчика |
| `src/drivers/net/ath9k/include/ath9k_hw.h` | Структура `ath_hw`, константы |
| `src/drivers/net/ath9k/include/ath9k_regs.h` | Регистры AR9285. Генерируется, см. ниже |
| `src/drivers/net/ath9k/include/ath9k_initvals.h` | Таблицы начальных значений. Генерируются |
| `src/drivers/net/ath9k/include/ath9k_priv.h` | Внутренние макросы драйвера |
| `src/net/802.11/` | Общий код 802.11: ассоциация (`assoc.c`), данные (`data.c`), скорости и каналы B |

**Генерируемые файлы.** `ath9k_regs.h` и `ath9k_initvals.h` создаёт `mk/gen_ath9k.py` из дерева Linux. Их не редактируют вручную. Изменения нужно вносить в скрипт.

Сборка — `src/drivers/net/ath9k/Makefile`, модуль `ar9285.so` (также `.ko` и `.elf`). Для тестов на хосте есть `tests/ath9k_test.c` (эмулятор регистров через `ath9k_test_read_hook` и `ath9k_test_write_hook`) и `tests/dot11_*`.

## Публичный API

| Функция | Что делает |
|---------|------------|
| `bool ar9285_init(void)` | Поиск адаптера, инициализация чипа, регистрация `wlan0` и Wi-Fi-операций. Вызывается из `src/net/core/net_service.c:43` |
| `bool ar9285_present(void)` | Адаптер найден на шине (не обязательно работает) |

Интерфейс получает имя `wlan0`, MAC берётся из EEPROM. Если MAC в EEPROM пустой или групповой, назначается локальный адрес `02:50:43:4f:53:xx`.

Операции Wi-Fi (`struct wifi_ops`) передаются в `wifi_device_register`: `scan`, `connect`, `disconnect`, `poll`, `is_connected`.

## Инициализация

**PCI** (`ar9285_init`):

1. `pci_enumerate` ищет `168C:002B`.
2. Включаются память и bus master. Если кэш-линия не задана, выставляется 16. Бит `0x41` конфигурации сбрасывается.
3. BAR0 отображается через `mmio_map`.

**Чип** (`ath9k_hw_init`):

1. Сброс с питания (`set_reset_reg`), пробуждение (`set_power`), чтение `AR_PHY_CHIP_ID`.
2. Чтение ревизии (`SREV`). Требуется AR9285. Ревизии ниже 1.2 принимаются с предупреждением, что таблицы инициализации могут не подойти.
3. `chip_test`, `rf_claim` — проверка и захват радиочасти.
4. `ath9k_eeprom_init` — чтение и проверка EEPROM (см. ниже).
5. `ath9k_hw_reset` — полный сброс с PLL, инициализацией регистров по таблицам, калибровкой шума (`start_nfcal`, `load_nf`) и начальной калибровкой (`init_cal`: `clc`, `cl_cal`, `pa_cal`).
6. `ath9k_hw_tx_init` и `ath9k_hw_rx_start` — кольца передачи и приёма.
7. `radio_tune(…, 6, …)` — настройка на канал 6 по умолчанию.

Ошибки инициализации пишутся в лог строками `ath9k:` и `ar9285:`. Для диагностики на железе выводятся версия SREV, версия EEPROM и при таймауте ассоциации счётчики `tx_ok` и `tx_fail`.

## EEPROM (`ath9k_eeprom.c`)

- Чтение через регистры `AR_EEPROM_STATUS_DATA` по 16-битным словам, адрес — `ATH9K_EEPROM_OFFSET` + смещение.
- Проверка: сумма всех слов XOR должна равняться `0xFFFF`, версия `0xE` (`ATH9K_EEP_VER`), ревизия не ниже `1`. Образы с порядком байт big-endian не поддерживаются.
- `ath9k_eeprom_set_txpower` задаёт мощность по каналу, скорости и ограничению. Таблицы PDADC и калибровки усиления заполняются по данным EEPROM.

## Сканирование и подключение

- **Сканирование** (`ar9285_wifi_scan`): каналы 1–11 по очереди, на каждом 110 мс (`AR9285_SCAN_DWELL_MS`). На каждом канале отправляется Probe Request. Результаты попадают в кэш сетевого стека `wifi_get_scan_results`.
- **Подключение** (`ar9285_wifi_connect`): SSID ищется в кэше, затем канал настраивается, MLME (`dot11_mlme_start_open`) проходит Authentication и Association. Таймаут 10 с (`AR9285_ASSOC_TIMEOUT_MS`), при срыве вызывается `wifi_notify_connect_failed(-11)`.
- **Отключение** (`ar9285_wifi_disconnect`): останавливает MLME и обнуляет BSSID в чипе.
- **Состояние** (`ar9285_wifi_is_connected`): MLME в состоянии `ASSOCIATED`.

## Данные

- Передача идёт через `ar_mlme_tx` для управляющих кадров и `ar9285_transmit` для данных. Данные 802.11 преобразуются в Ethernet через `src/net/802.11/data.c`.
- Приём: `rx_poll` вычитывает FIFO RX. `handle_mgmt` передаёт управляющие кадры в MLME, `handle_data` поднимает данные наверх через `net_device_receive`, но только в состоянии `ASSOCIATED`.
- Очистка завершённых передач: `ath9k_hw_tx_reap` в каждом цикле опроса.
- Скорость данных — 1 Мбит/с (`ATH9K_HWRATE_1M`), управления скоростью нет.

## Ограничения

- **Только открытые сети.** Подключение к сети с WEP или WPA отклоняется (`wifi_security_name`). Шифрования CCMP/WPA2 нет, пароль в `ar9285_wifi_connect` игнорируется.
- **Только 2,4 ГГц, HT20, каналы 1–11.** Канал 12–14 и 5 ГГц не сканируются.
- **Нет прерываний.** Приём и таймеры обрабатываются в `ar9285_wifi_poll`, которую вызывает сетевой сервис.
- **Нет управления скоростью.** Все данные передаются на 1 Мбит/с CCK, поэтому пропускная способность низкая.
- **Нет калибровок в работе.** Калибровки шума и PA выполняются только при инициализации. Периодический ANI (адаптивная подстройка) не реализован, как и подавление помех (`spur_mitigate` не полный).
- **Радио не проверено на железе.** Код проходил хостовые тесты с эмулятором регистров, но реальная передача и приём не подтверждены. В списке задач проекта есть пункт «снять rfkill на AR9285», его нужно закрыть до проверки радио.
