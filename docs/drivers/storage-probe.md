# Перечисление контроллеров хранения (`storage_probe`)

`src/drivers/storage/storage_probe.c` один раз проходит по PCI и составляет список контроллеров хранения и USB. Остальные драйверы хранения (AHCI, xHCI, EHCI) берут из этого списка свои контроллеры. Сам файл ничего не инициализирует и не работает с устройствами, он только классифицирует функции PCI.

## Расположение

| Файл | Назначение |
|------|------------|
| `src/drivers/storage/storage_probe.h` | Публичный API |
| `src/drivers/storage/storage_probe.c` | Классификация PCI-функций |
| `src/drivers/storage/storage_types.h` | Общие структуры и константы для всех драйверов хранения |

## Публичный API

| Функция | Что делает |
|---------|------------|
| `storage_probe_init()` | Перечисляет PCI один раз (повторные вызовы ничего не делают) |
| `storage_controller_count()` | Число найденных контроллеров |
| `storage_controller_list(out, cap)` | Копирует список в буфер вызывающего кода |

## Классификация

| Класс PCI | Подкласс | Интерфейс | Тип контроллера | Имя |
|-----------|----------|-----------|-----------------|-----|
| `01` (mass storage) | `06` (SATA) | `01` (AHCI) | `STORAGE_CONTROLLER_AHCI` | `ahci0`, `ahci1`… |
| `01` | `08` (NVM) | `02` или `03` | `STORAGE_CONTROLLER_NVME` | `nvme0`… |
| `0C` (serial bus) | `03` (USB) | `30` | `STORAGE_CONTROLLER_XHCI` | `xhci0`… |
| `0C` | `03` | `20` | `STORAGE_CONTROLLER_EHCI` | `ehci0`… |

Контроллеры UHCI (`00`) и OHCI (`10`) в журнал пишутся, но в список не попадают: драйвера для них нет. Лимит — 8 контроллеров (`STORAGE_CONTROLLER_LIMIT`).

Для AHCI базовый адрес берётся из BAR5 (ABAR). Для остальных — из BAR0. Если BAR64-битный, читается старшая половина.

## Структура `storage_controller_info`

| Поле | Содержимое |
|------|------------|
| `name` | Имя вида `ahci0` |
| `register_base` | Физический адрес регистров (ABAR или BAR0) |
| `vendor_id`, `device_id` | Идентификаторы PCI |
| `bus`, `slot`, `function` | Положение на шине |
| `type` | Код `STORAGE_CONTROLLER_*` |
| `programming_interface` | Байт интерфейса программирования |

## Структура `storage_device_info`

Общая для всех драйверов структура накопителя, которую заполняют ATA PIO, AHCI, xHCI и EHCI:

| Поле | Содержимое |
|------|------------|
| `name` | Имя `/dev/sdX` (9 байт вместе с нулём) |
| `model`, `serial` | Строки из IDENTIFY или INQUIRY (до 40 и 20 символов) |
| `sector_count`, `sector_size` | Размер в секторах и размер сектора |
| `channel`, `drive`, `controller`, `port` | Положение: канал и диск для ATA, порт для остальных |
| `writable`, `selected`, `operational` | Флаги: запись разрешена, накопитель выбран, готов к работе |
| `transport` | Код `STORAGE_TRANSPORT_*` (ATA PIO, AHCI, USB MSC, USB EHCI) |

## Где используется

- `src/drivers/storage/ahci.c`, `src/drivers/usb/xhci.c`, `src/drivers/usb/ehci.c` — берут контроллеры своего типа через `storage_controller_list`.
- `src/drivers/storage/ata_pio.c` — не использует список, ATA PIO находит устройства по фиксированным портам `0x1F0` и `0x170`.
- `src/drivers/storage/block_device.c` — блочный слой использует `storage_types.h`.

## Ограничения

- NVMe распознаётся, но драйвера нет. Контроллер попадает в список, а накопитель с него не появляется.
- Контроллеры UHCI и OHCI не поддерживаются, USB 1.1 устройства через них недоступны.
- Нет сортировки: порядок контроллеров зависит от порядка PCI. При добавлении или замене контроллера буквы дисков могут сдвинуться.
- Лимит 8 контроллеров. Остальные молча отбрасываются.
- `storage_types.h` задаёт ограниченные размеры строк (модель 40 символов, серийный номер 20). Длинные строки обрезаются.
