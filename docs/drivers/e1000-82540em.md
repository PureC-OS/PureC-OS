# Драйвер Intel e1000 (82540EM)

Драйвер сетевой карты Intel 82540EM (PCI `8086:100E`), которую эмулируют QEMU (`-device e1000`) и VirtualBox. Работает через MMIO, кольца дескрипторов RX и TX по 16 элементов, опрос без прерываний. Интерфейс в системе получает имя `eth0`.

## Публичный API

`bool e1000_82540em_init(void)` ищет карту, включает её и регистрирует сетевое устройство через `net_device_register`. Вызывается из `src/net/core/net_service.c:40` вместе с другими сетевыми драйверами. Возвращает `false`, если карты нет или регистрация не удалась.

## Инициализация

1. `pci_enumerate` ищет `8086:100E`. BAR0 должен быть памятью (бит 0 сброшен).
2. Включаются память и bus master, BAR отображается через `mmio_map` (128 КБ).
3. `reset_controller`: маскируются прерывания (`IMC`), ставится бит `CTRL.RST`, ждётся его сброс (до 1 000 000 итераций).
4. `read_mac` читает MAC из регистров `RAL` и `RAH`. Адрес с нулями, все `FF` или с групповым битом отклоняется.
5. `allocate_dma` выделяет кольца RX и TX по 16 дескрипторов, для каждого элемента буфер 2048 байт.
6. Таблица многоадресной фильтрации `MTA` обнуляется. `RCTL` получает `BAM` (приём широковещательных кадров) и `SECRC` (отбрасывание CRC).
7. Кольца программируются (`RDBAL`, `RDLEN`, `TDBAL`, `TDLEN`), `CTRL.SLU` выставляет «link up».
8. Устройство регистрируется как `eth0` с MTU 1500.

Если регистрация не удалась, карта отключается (`RCTL`, `TCTL` = 0), DMA освобождается.

## Передача и приём

- **Передача** (`e1000_transmit`): кадр копируется в буфер текущего дескриптора, ставятся флаги `EOP`, `IFCS` и `RS`, индекс `TDT` сдвигается. Если дескриптор ещё занят (`DD` не выставлен), кадр отбрасывается, функция возвращает `false`. Защита от параллельной передачи — атомарный флаг `tx_locked`.
- **Приём** (`e1000_poll`): до `budget` дескрипторов с выставленным `DD`. Кадр с `EOP`, без ошибок и не больше `NET_ETHERNET_MAX_FRAME_SIZE` передаётся в `net_device_receive`. Остальные учитываются как `rx_errors`. Дескриптор возвращается карте (`RDT`).
- **Состояние связи** (`e1000_link_up`): бит `LU` в `STATUS`.

## Ограничения

- Работает только с 82540EM. Другие варианты e1000 (например, 82543GC) обслуживаются отдельным драйвером, см. [e1000-82543gc.md](e1000-82543gc.md).
- Имя `eth0` захардкожено. Если одновременно найдена вторая карта e1000 или PCnet, имена могут совпасть.
- Прерывания не используются: приём обрабатывается, только когда сетевой сервис вызывает `poll`.
- Кадры передаются один раз: при ошибке нет повтора, учитываются только потери через `rx_errors`.
- Буферы фиксированные по 2048 байт, кадры длиннее не передаются (`length > E1000_DMA_BUFFER_SIZE` отклоняется).
- Таблица `MTA` обнуляется, групповые адреса не добавляются и не принимаются. Фильтрация по адресу — только по собственному MAC и широковещательным кадрам.
