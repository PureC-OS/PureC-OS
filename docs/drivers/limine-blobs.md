# Заголовки `limine_vbr.h` и `limine_stage2.h`

В каталоге `src/drivers/storage/` лежат два сгенерированных C-заголовка с бинарными данными загрузчика Limine. Это не драйверы: в файлах нет ни одной функции, только массивы байт.

| Файл | Размер | Содержимое |
|------|--------|-----------|
| `src/drivers/storage/limine_vbr.h` | 512 байт (`limine_vbr_len`) | Загрузочный сектор (VBR) Limine, в заголовке которого есть строка `LIMINE` |
| `src/drivers/storage/limine_stage2.h` | 322 560 байт (`limine_stage2_len`) | Второй этап загрузчика Limine, который читает конфигурацию и ядро |

## Использование

В репозитории нет ни одного файла, который ссылается на `limine_vbr` или `limine_stage2` (проверено поиском по всему дереву, кроме самих заголовков). Значит, сейчас они никуда не встраиваются. Предполагаемый сценарий — установка загрузчика на диск без внешних файлов, но его код в проекте не найден.

Для установки загрузчика сейчас используется другой путь: `mk/make_esp_image.sh` и файлы из `bin/` (см. [README](../../README.md) и `mk/`).

## Ограничения и рекомендации

- Файлы сгенерированы из бинарников Limine. Вручную их менять нельзя. Для обновления нужна та же версия Limine, из которой они получены. Версия в файлах не записана.
- Заголовки занимают около 27 000 строк. Они раздувают поиск по коду и индексацию, поэтому их стоит вынести в отдельный каталог, например `assets/` или `boot/limine/`, или удалить, если установщик на них не опирается.
- Перед удалением стоит убедиться, что установщик не загружает эти данные иным способом (например, через `include` с другим именем файла).
